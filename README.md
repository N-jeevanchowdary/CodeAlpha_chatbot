# 🤖 AI-Powered Web Chatbot (CodeAlpha Internship Project)

An interactive, responsive web-based AI Assistant Chatbot built using **Python Flask**, **HTML5/CSS3**, and **JavaScript** for instant automated responses to user queries.

---

## 🚀 Features

* **Interactive Web Interface:** Modern, clean, and responsive chat UI with seamless user experience.
* **Instant Smart Responses:** Fast keyword-based pattern matching engine to process user queries in real-time.
* **Domain Awareness:** Pre-loaded with answers for Cloud Computing, AWS, Azure, Flask, and internship FAQs.
* **REST API Endpoint:** Backend Flask route (`/get_response`) using JSON communication for dynamic frontend updates.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Protocol:** HTTP REST (JSON)

---

## 💻 How to Run Locally

1. **Clone the repository:**
   `git clone https://github.com/N-jeevanchowdary/CodeAlpha_chatbot.git`

2. **Navigate to the project folder:**
   `cd CodeAlpha_chatbot`

3. **Install Flask:**
   `pip install flask`

4. **Run the application:**
   `py app.py`

5. **Open in browser:** 
   `http://127.0.0.1:5000`
